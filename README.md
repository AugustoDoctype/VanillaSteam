# 🎮 Nemo - Radar de Ofertas Premium

O Nemo é um bot para Discord que monitora a Steam em busca de ofertas "Nível AAA". Ele filtra automaticamente jogos populares e bem avaliados, entregando um Top 10 organizado com conversão direta para Real.

## ✨ Funcionalidades
- **Top 10 Mensal/Semanal:** Ranking com pódio de medalhas.
- **Filtro de Qualidade:** Apenas jogos com +20.000 avaliações ou Metacritic 85+.
- **Conversão de Moeda:** Busca a cotação do Dólar em tempo real para o BRL.
- **Selo de Pechincha:** Alerta visual para descontos de 90% ou mais.

## 🚀 Como rodar o projeto
1. Clone o repositório: `git clone https://github.com/seu-usuario/NemoSteam.git`
2. Crie seu ambiente virtual: `python -m venv venv`
3. Instale as dependências: `pip install -r requirements.txt`
4. Configure o seu `.env` com seu Token do Discord (veja o `.env.example`).
5. Execute: `python bot.py`
